## 🛠️ Local Development Setup

To run this portfolio website locally, follow these steps:

### 1. Clone the Repository
```bash
git clone https://github.com/SyedAsad108/Portfolio.git
cd Portfolio
```

### 2. Install Dependencies
Make sure you have Node.js installed, then run:
```bash
npm install
```

### 3. Run the Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173` (or the port indicated in your console) to view the site.

### 4. Build for Production
To generate a production build of the static site in the `dist` directory:
```bash
npm run build
```
